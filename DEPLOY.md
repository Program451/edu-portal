# Деплой ЕдуПортал на Render (бесплатно, с постоянной ссылкой)

Что уже сделано в проекте:
- `litestream.yml` — непрерывное резервное копирование базы данных `database.db` в Cloudflare R2, автоматическое восстановление при перезапуске.
- `r2-storage.js` — резервное копирование и восстановление загруженных файлов (домашки, видео, книги) через тот же R2.
- `render.yaml` — готовый рецепт деплоя для Render.

Код `server.js` **не переписан** на другую базу данных — он как был на `better-sqlite3`, так и остался. Просто теперь файл базы и загруженные файлы дублируются в облако и восстанавливаются при старте, поэтому ничего не теряется на бесплатном тарифе Render.

Полная инструкция ниже — от создания аккаунтов до рабочей ссылки. Всё бесплатно, код виден только вам (приватный репозиторий).

---

## Шаг 0. Установите Git (если ещё нет)

Проверьте, установлен ли git:
```
git --version
```
Если пишет "команда не найдена" — скачайте с https://git-scm.com/downloads и установите (Windows: просто next-next-next, ничего менять не нужно).

---

## Шаг 1. GitHub — регистрация и приватный репозиторий

1. Зайдите на https://github.com/signup, зарегистрируйтесь (email + пароль). Это бесплатно.
2. После входа нажмите **+** в правом верхнем углу → **New repository**.
3. Заполните:
   - **Repository name**: `edu-portal` (или любое своё)
   - Ниже выберите **Private** (обязательно — иначе код будет виден всем)
   - Остальное не трогайте (не добавляйте README/gitignore — у вас уже есть проект)
4. Нажмите **Create repository**.
5. GitHub покажет страницу с командами. Оставьте эту вкладку открытой — команды понадобятся в Шаге 2.

## Шаг 2. Загрузка проекта на GitHub

Откройте терминал (Windows — PowerShell, Mac/Linux — Terminal) в папке с проектом (та, что я вам прислал, распакованная) и по очереди выполните:

```bash
git init
git add .
git commit -m "Первая загрузка проекта"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/edu-portal.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` на свой логин GitHub (он есть в адресе страницы репозитория, которую вы создали в Шаге 1).

При первом `git push` GitHub попросит войти — откроется окно браузера, войдите под своим аккаунтом и разрешите доступ. Дальше пуш пройдёт сам.

Проверка: откройте `https://github.com/ВАШ_ЛОГИН/edu-portal` в браузере — должны увидеть все файлы проекта (значок замка означает, что репозиторий приватный).

**Важно:** файл `.env` (если вы его создавали локально, с настоящими паролями/ключами) НЕ должен попасть в GitHub. Проверьте, что в проекте есть файл `.gitignore` со строкой `.env` — если нет, создайте его до `git add .`:
```bash
echo ".env" > .gitignore
echo "node_modules" >> .gitignore
```

---

## Шаг 3. Cloudflare R2 (бесплатное облачное хранилище, 10 ГБ)

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно, карта не нужна для free tier R2).
2. В боковом меню слева найдите **R2 Object Storage** → **Create bucket**.
3. Название бакета: `edu-portal-backup` → **Create bucket**.
4. Слева в разделе R2 откройте **Manage API tokens** → **Create API token**.
5. Права доступа: **Object Read & Write**, область действия — только этот bucket.
6. После создания токена Cloudflare покажет 4 значения — **скопируйте и сохраните их сразу**, секретный ключ показывается только один раз:
   - **Access Key ID**
   - **Secret Access Key**
   - **Endpoint** (вида `https://ваш_account_id.r2.cloudflarestorage.com`)
   - Имя бакета: `edu-portal-backup`

---

## Шаг 4. Render — деплой

1. Зайдите на https://render.com → **Get Started** → войдите через **GitHub** (это самый простой способ — сразу даёт Render доступ к вашим приватным репозиториям).
2. При первом входе Render спросит, к каким репозиториям дать доступ — выберите **Only select repositories** → `edu-portal` (не открывайте доступ ко всем подряд).
3. На дашборде Render нажмите **New** → **Blueprint**.
4. Выберите репозиторий `edu-portal`. Render автоматически найдёт файл `render.yaml` в проекте и покажет, какой сервис будет создан.
5. Render попросит заполнить переменные окружения (те, что помечены `sync: false`):
   - `GROQ_API_KEY` — ваш ключ (если используете ИИ-проверку домашних заданий; можно оставить пустым, если не используете)
   - `ALLOWED_ORIGINS` — пока оставьте пустым
   - `R2_BUCKET` → `edu-portal-backup`
   - `R2_ENDPOINT` → endpoint из Шага 3
   - `R2_ACCESS_KEY_ID` → ключ из Шага 3
   - `R2_SECRET_ACCESS_KEY` → секретный ключ из Шага 3
6. Нажмите **Apply**. Render начнёт сборку — это займёт 2-5 минут, статус видно в реальном времени в логах.
7. Когда статус станет **Live**, вверху страницы сервиса будет ваша постоянная ссылка вида:
   `https://edu-portal.onrender.com`

---

## Шаг 5. Проверка

1. Откройте ссылку из Шага 4 — должна открыться главная страница (`index.html`).
2. Войдите под `admin` / `admin123` → **сразу смените пароль** в настройках администратора.
3. Загрузите тестовый файл (например, домашнее задание или книгу в библиотеку).
4. В Render зайдите на страницу сервиса → **Manual Deploy** → **Restart Service**.
5. После перезапуска (30-60 сек) откройте сайт снова и проверьте, что загруженный файл и все данные на месте — это подтверждает, что резервное копирование в R2 работает.

## Важно про бесплатный тариф Render

- Сервис "засыпает" после 15 минут без запросов. Первый заход после сна грузится 30-60 секунд — это нормально, не баг.
- 750 бесплатных часов в месяц — для одного постоянно работающего сервиса этого достаточно (в месяце ~730 часов).
- Обновить сайт после правок в коде: просто `git add . && git commit -m "..." && git push` — Render передеплоит автоматически.
