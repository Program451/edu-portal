Загрузите файл Excel (.xlsx) или CSV. Обязателен только столбец «ФИО» — логин и пароль сгенерируются автоматически, если не указаны. Можно импортировать любую роль: добавьте в файл столбец «Роль» (студент / преподаватель / оператор / администратор) — тогда роль для каждой строки берётся из него. Если такого столбца нет — используется роль, выбранная ниже, для всех строк файла. Скачать шаблон.
